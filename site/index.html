GitHub Stars Ranking: user manual

The most-starred GitHub repositories (up to 10,000, at least 1,000 stars), rebuilt every week; the date is in the title bar. Compare with an earlier ranking to see what is rising, falling or new.

Quick start

  • The table shows the first 300 matches. Narrow it with the phrase box and with the Users, Topics and Languages panels on the right.
  • Click a row to see Repo Info at the bottom: description, topics, license, last push, open issues and pull requests, languages, and charts of position and stars over time. Double-click opens the repository on GitHub.
  • Choose Compare to to compare with an earlier ranking (from a week to several years back).

Toolbar

Compare toThe ranking to compare with (by default the most recent one at least a year old, or the newest available if the history is shorter). Turns on the Change and Gain columns and the Sort by and Show options.
Sort byStars, Stars gained, Stars gained %, Positions gained.
ShowAll, New (created since that ranking), Climbers (moved up), Fallers (moved down).
PhraseSearches name, name+desc or desc (Search in). It is a case-insensitive regular expression, e.g. rust|zig. Clear resets it.

Columns

  • Rank: position in the full ranking, not affected by filters.
  • Change: positions gained (↑) or lost (↓) since the chosen ranking. NEW = created after it. n/a = existed already but is missing from that ranking (it was below the cut-off, or the data has a gap); hover for details.
  • Gain: stars gained since then, and the percentage. For new repositories all stars count as gain.
  • Also: language (coloured dot), Created (year-month), Forks, Subscribers (watchers) and Topics.

Filter panels

  • Tick checkboxes in Users (owners), Topics and Languages. Several ticks in one panel mean “any of them”; different panels combine with “and”.
  • Clear selection unticks everything. Each panel has its own name filter. Very common language names are hidden from Topics.

Good to know

  • Repo Info details are fetched by your browser from GitHub's public API (60 requests per hour per IP address). If you hit the limit, wait a while.
  • The ranking is rebuilt once a week, so Change compares weekly snapshots.
