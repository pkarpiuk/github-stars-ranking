Help

The Chrome Web Store allows you to browse and search Google Chrome extensions. Unfortunately, they are sorted in a way only known to Google and with minimal filtering.

This website allows you to:

  • Creating ranking lists taking into account the average rating (rate), the number of users rated (rate_users), and the number of users (user_count),
  • Comparison of ranking lists from different periods (so we can see trends: which extension is gaining popularity and which is falling).

The ranking includes extensions that meet the following conditions:

  • rate >= 3: user rating is min. 3.00
  • rate_users >= 10: at least 10 users have rated,
  • user_count >= 1000: minimum 1000 users

Tip: A double click on the table row opens the extension page in a new browser tab.
